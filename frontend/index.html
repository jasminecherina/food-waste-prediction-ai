About This Model

This prototype uses a Random Forest regression model to estimate food waste from kitchen activity, environmental conditions, previous waste, and food category.

Research limitation: the model was trained on a practice dataset. It has not been validated for fruit and vegetable wholesale markets. Predictions should not be treated as measured quantities.

History is stored locally in this browser. It is not shared with a database.
